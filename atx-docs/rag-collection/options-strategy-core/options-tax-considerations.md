# xFinance desk: Options tax & assignment (HNWI checklist)

**One-sentence definition:** A **checklist** of how listed equity options often interact with tax reporting, holding periods, and assignment — so advisors ask the CPA the right questions.

**Best market conditions:** **N/A** — applies whenever options are opened, closed, exercised, or assigned.

**Risk bucket:** **N/A (cross-cutting)** — mistakes here are **compliance / cash-planning** risk, not delta.

**Payoff profile:** **N/A**

**Position sizing rules:** **N/A** — but tax lots can argue for **smaller** assignments into clean lots.

**Worked example (illustrative, not advice):** Assigned **100** shares from CSP — broker may report cost basis **strike − premium**; your CPA may adjust for fees, wash sales, or lot selection if you hold duplicates.

**When to avoid:** Using this doc as a substitute for **CPA** review on **QSBS**, **charitable**, **grant**, or **cross-border** positions.

**Tax & assignment (expanded checklist — not tax advice):**

| Topic | High-signal note |
|-------|------------------|
| **1256 contracts** | Many broad-based **index** options get **60/40** character vs **1256** rules — verify instrument + broker tax packet. |
| **Equity options** | Often short/long-term rules follow stock rules on **exercise/assignment**; closing before expiry is usually a capital gain/loss event — confirm lot matching. |
| **Wash sale** | Rebuying “substantially identical” stock/options around a loss can **defer** loss — track **30-day** windows on large lines. |
| **PM AMT** | Incentive / AMT interactions are **not** modeled here — CPA required for ISO/NQ interplay. |
| **Early exercise** | Short calls into **dividend** dates can be assigned for dividend capture — watch **ex-div** calendar. |
| **Assignment funding** | CSP assignment needs **cash** or margin capacity + possible **margin interest** (planning). |

**Quick reference**

| Event | Ask CPA |
|-------|---------|
| **Exercise** | Holding period / character / AMT |
| **Assignment** | Basis step-up/down; wash links |
| **Spread expiry OTM** | Typically closing transaction only |

## Guardrails

- Export broker **1099-B** / options supplement annually; reconcile to internal lot ledger.
- Document **intent** (income vs hedge vs conversion) in trade notes for audit.
