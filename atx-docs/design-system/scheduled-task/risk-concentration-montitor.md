# Job name
Risk & Concentration Monitor

# Purpose
Updates portfolio beta, sector concentration, single-name risk, and simple VaR; alerts on breaches.

# Suggested frequency
Daily (post-market)

# Per-portfolio summary example

“Risk scan: Tech concentration 48% (+12% vs target). Portfolio beta 1.18. VaR (95%, 1-day) $4,200.”
