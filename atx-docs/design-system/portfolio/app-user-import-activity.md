# App-user broker holdings import (`/import-activity`)

**Shipped:** PLAN **710** (app ≥2.10.14). **Partial row import + preview masking** (app ≥3.1.2).

- **UX copy (canonical):** [`src/app/import-activity/import-activity-copy.ts`](../../../src/app/import-activity/import-activity-copy.ts) — page hero title **Import broker holdings & activities**; intro on safe background import and xOptions / monitoring alignment; in-card **Supported Files** (portfolio holdings, Account History, legacy positions), **How to Import** (CSV ↔ Broker ref, **Use for import**, preview → row select → import), **Options note** (net-long only); **Clean first, then import** panel copy. Tests: [`tests/unit/import-activity-copy.test.ts`](../../../tests/unit/import-activity-copy.test.ts).
- **UI:** [`src/app/import-activity/page.tsx`](../../../src/app/import-activity/page.tsx) + [`import-activity-client.tsx`](../../../src/app/import-activity/import-activity-client.tsx); entry CTA from [`/portfolios`](../../../src/app/portfolios/page.tsx) (**Import activities** / **Watchlist & Alerts**). After **Preview (dry run)**, each detected broker account row has an **Import** checkbox (default on). **Run import now** sends **`mappings`** only for checked rows that match a portfolio account (`extAccountId` + custodian `type`). Uncheck all → button disabled; server rejects apply if **no** row is mapped when the CSV has accounts.
- **Default account ref stability:** Idempotent default-book provision (**Next `provisionDefaultPortfolioForUser`**, Spring **`DefaultPortfolioProvisionService`**, **≥3.7.3**) does **not** overwrite **`extAccountId`** / broker **`type`** on an existing default account, so broker CSV matching and **Account details** edits are not wiped by the next login or shell provision. See **[`auth-and-access.md`](../../guides/auth-and-access.md)** (re-login) and **`current-state-features.md`** (portfolio stack).
- **Preview table:** Broker ref and “Maps to” stored ref use **`maskAccountXrefForDisplay`** (e.g. **`••••` + last four**); matching still uses **full** ids from the file and DB (tooltip on broker ref column).
- **Mapping keys:** Must match the holdings parser / executor: **`accountRef || label || "default"`** (same as [`applyBrokerHoldingsToMappedAccounts`](../../../src/modules/portfolio-import/broker-holdings-import.ts)); the UI uses the same key when building **`mappings`**.
- **API:** [`POST /api/import/broker`](../../../src/app/api/import/broker/route.ts) — `requireApprovedAppUserSession`; body mirrors admin import (`portfolioId`, `broker`, `exportType: holdings`, `csv`, `mappings`, optional `fidelityHoldingsDefaultAccountRef`, `dryRun`). **`mappings`** may be a **subset** of parsed broker account keys; omitted keys are skipped on apply. **[`POST /api/import/broker/clean`](../../../src/app/api/import/broker/clean/route.ts)** — same session + portfolio gate; removes all positions, import-job rows, and portfolio `sync-broker` tasks (UI “clean slate” before re-import).
- **Validation:** [`validateBrokerImportMappings`](../../../src/modules/portfolio-import/app-broker-import-job.ts) — validates only **entries present** in **`mappings`**; requires **at least one** mapped row when the CSV parsed to one or more accounts. **`brokerImportLocked`** unchanged (not set by this flow for app user).
- **Execution:** Mongo **`app_broker_import_jobs`** (CSV ≤ **1 MiB** chars) + ephemeral **`admin_scheduled_tasks`** (`category: sync-broker`, `appBrokerImportJobId`, `portfolioId`, `nextRunAt` now). Next **`executeScheduledTask`** → [`runScheduledAppBrokerImportTask`](../../../src/modules/portfolio-import/app-broker-import-job.ts); task document removed after run; **`admin_task_runs`** kept. Rows without a mapping produce a **zero-import** result row (no error string).
- **Admin parity:** Holdings pipeline shared with [`broker-holdings-import.ts`](../../../src/modules/portfolio-import/broker-holdings-import.ts); admin-only route remains **`POST /api/admin/import/broker`** (same partial-**`mappings`** semantics and preview masking in [`broker-holdings-import-panel.tsx`](../../../src/app/admin/portfolios/ui/broker-holdings-import-panel.tsx)).
