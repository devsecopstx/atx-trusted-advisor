# xFinance Branding Docs

This folder contains image assets plus the 2026 refresh docs used by prompt generation and design review workflows.

## Documents

- `xfinance-brand-prompts.md`: canonical prompt templates and variants
- `xfinance-branding-tags.md`: reusable tag taxonomy and presets
- `xfinance-color-palette.md`: color tokens and usage rules
- `xfinance-typography.md`: typography system and readability constraints
- `xfinance-brand-validation.md`: prompt dry-run and QA scorecard

## Workflow

1. Start from `xfinance-brand-prompts.md`.
2. Apply relevant preset from `xfinance-branding-tags.md`.
3. Validate generated outputs with `.cursor/skills/xfinance-brand`.
4. Record findings in `xfinance-brand-validation.md` (or new batch-specific validation docs).
