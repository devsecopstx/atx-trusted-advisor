# Test UI

## Goal

Verify core user journeys remain functional and responsive after frontend changes.

## Use This Skill When

- UI behavior changed
- A regression is reported in frontend flows
- You need quick confidence before merge

## Workflow

1. Identify top critical flows (auth, onboarding, core actions).
2. Run smoke tests and key interaction checks.
3. Capture failures with reproducible steps.
4. Apply focused fixes and re-verify.

## Output

- Flows verified
- Failing scenarios with repro
- Fix status and residual risk
