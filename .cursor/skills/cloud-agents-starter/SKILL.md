# Cloud Agents Starter

## Goal

Initialize a cloud-deployable agent service with clear architecture, environment setup, and operational guardrails.

## Use This Skill When

- Starting a new cloud-hosted agent project
- Standardizing deployment and runtime config
- Creating a baseline for secure, observable agent execution

## Workflow

1. Define service boundaries and task lifecycle.
2. Set environment variables and secrets contract.
3. Add health, readiness, and basic telemetry.
4. Configure deployment target and runtime limits.
5. Add smoke validation and rollback guidance.

## Output

- Minimal architecture plan
- Required env/config checklist
- Deployment runbook starter
- Validation checklist
